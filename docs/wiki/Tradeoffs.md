# Tradeoffs (결정 로그)

수치는 모두 `make run` 로그와 `output/report.md` 에서 가져왔습니다.

| # | 상황 | 선택지 | 결정 | 비용 | 다시 볼 조건 |
|---|---|---|---|---|---|
| 1 | 결측 4,262셀이 workclass, occupation, native-country 세 범주 컬럼에 몰려 있음 | 행 제거 / 최빈값 대체 / "Unknown" 범주화 | 행 제거 (`dropna`) | 2,399행(7.4%) 손실. 제거 전후 고소득 비율 24.08% > 24.90% (0.82%p), 근로시간 평균 40.44 > 40.93 으로 왜곡이 작음을 검증 | 결측 행도 예측해야 하는 서비스가 될 때 |
| 2 | 로딩 도구 선택 | Pandas / Polars | 비교는 둘 다, 이후 단계는 Pandas | Polars 가 2.21배 빠르지만 0.01초 차이 | 데이터가 수백만 행으로 커질 때 |
| 3 | 로딩 비교의 측정 범위 | 순수 파싱만 / 분석 가능한 상태까지 | 분석 가능한 상태까지 (Polars 의 strip, 결측 치환 포함) | Polars 가 덜 빨라 보임 | 없음 (공정 비교 원칙) |
| 4 | 등분산 가정 | Student t / Welch t | Levene 로 확인 후 Welch t (stat 20.63, p < 0.001 로 등분산 기각) | 검정 하나 추가 | 등분산이 유지되는 다른 데이터셋 |
| 5 | 비정규 분포 (40시간 봉우리) | t 만 / 비모수 병행 | Mann-Whitney U 병행, 평균 차이와 방향 일치까지 검사 | 해석 혼동 위험 (평균 vs 순위) > 보고서에 검정 대상 열을 두어 구분 | 없음 |
| 6 | 대표본 (n = 30,139) 에서 p 만 보면 과장 | p 만 / 효과크기 병기 | Cohen's d, 95% CI 병기 | 표가 길어짐 | 없음 |
| 7 | 결론 문장과 검정의 불일치 (중앙값 동일) | 평균 검정만 / 비율 검정 추가 | 40시간 초과 이진화 + 카이제곱 | 임계값 40 이 고정값 | 다른 나라나 연도 데이터 (표준 근무 시간이 다를 때) |
| 8 | 근로시간 효과가 나이, 교육의 그림자일 가능성 | 단변량만 / 다변량 통제 | statsmodels 로지스틱 회귀 (age, education-num 통제) | 의존성 추가 | 통제 변수를 더 넣어야 할 때 (직업 등) |
| 9 | 보조가설(연령) 다중비교 | Bonferroni 보정 / 탐색적이라 명시 | 탐색적 보강으로 한정하고 보고서에 한계 명시 | 보조가설을 근거로 쓸 수 없음 | 보조가설을 주장에 쓰려 할 때 |
| 10 | 분류 지표 | accuracy / F1 / MSE, R2 | accuracy + F1 (+ recall). MSE, R2 는 회귀 지표라 제외 | | |
| 11 | 저장 모델 | LogisticRegression / RandomForest | LogisticRegression (F1 0.6601 vs 0.6746) | F1 0.0145 낮음 | 해석보다 성능이 중요해질 때 |
