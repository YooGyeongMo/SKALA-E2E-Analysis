# 팀원 의견/회고 공간

자동 생성되는 output/report.md는 수치와 사실만 담는다.
이 폴더는 사람의 해석과 회고를 담는 공간이다.

## 작성 방법
1. 자기 파일(아이디.md)을 열어 아래 4개 섹션을 채운다
2. 브랜치 파서 PR로 올린다 (다른 코드와 동일한 절차, 리뷰 1명)
3. 제출 PDF의 의견 파트는 이 파일들을 취합해 구성한다

## 섹션 구성
- 개별 의견: 내가 맡은 파트에서 내린 기술적 판단과 이유
- 팀 의견: 협업 방식(이슈/PR/CI)에 대한 회고
- 배운 점: 이번 과제에서 새로 알게 된 것
- 개선 의견: 시간이 더 있다면 하고 싶은 것
